niuz data pipeline + LLMs

News from Portugal, Israel and the world, reduced to single statements, each carrying the source's exact words. A statement is confirmed when two independent outlets carry it.

  • How it works

    One adapter per kind of source (RSS articles, podcasts) turns everything into the same shape. Podcasts run as a workflow per episode: transcription over byte-range slices, transcript to object storage. A model proposes statements with a quote, and code keeps only those whose quote really is in the source. Embeddings match statements across outlets, with a model judge for the uncertain band, which also catches contradictions.

  • What was hard

    Not letting the model invent anything. Summaries keep only sentences that cite a real statement. The Hebrew and Portuguese editions are translations of the checked English page, rejected if any number changes. Every paid model call sits under a daily budget.

  • Stack

    Cloudflare Workers, D1, Vectorize, Workers AI, Workflows, R2.

Lingush full-stack product

Native Portuguese podcasts as listening practice: real audio, word-by-word translation, and sentence-by-sentence playback at full speed.

  • How it works

    A Next.js and React app on Postgres through Prisma, with sign-in, Stripe payments and Sentry, plus an Android build with Capacitor. Behind it, a Python audio pipeline transcribes episodes, splits them into sentences, translates and adds speech.

  • What it shows

    The whole product on one person: the data model, the pipeline, the UI, payments and the Android build.

  • Stack

    TypeScript, React, Next.js, Postgres, Prisma, Stripe, Python, Capacitor.

Jarvis Arena voice agents

Runs a scripted conversation against a voice agent and returns a video of it, a pass or miss for every step, and what it cost.

  • How it works

    A synthetic voice says each line, the agent hears it through real speech-to-text (so mishearings are real), then acts in a real Chromium window and answers out loud. Checks run after each line. The whole screen is recorded with both voices and stored next to the transcript and the cost.

  • What it shows

    Testing an AI product the way a user meets it, end to end, with numbers instead of impressions. Everything runs in one Cloudflare account: a Worker, one container per run, D1, R2. Open source.

  • Stack

    Cloudflare Workers, Containers, D1, R2, Workers AI, speech APIs.

podqast phone-first web app

Every episode of 550 podcasts in 29 languages, searchable by subject and by who is on them, with a player that keeps going while you browse.

  • How it works

    Plain RSS into a database on a schedule. One HTML page, one script, one stylesheet: no framework and no runtime dependencies. Resume where you left off, speed, lock-screen controls, installable on a phone.

  • What it shows

    Keeping something small and fast on purpose, and running it in public: real crawler traffic, query costs bounded by indexes and caching, decisions taken from what visitors actually do.

  • Stack

    Cloudflare Workers, D1, vanilla JavaScript, Media Session API.
